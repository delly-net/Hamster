# 简介

针对MiniNamedAttribute特性进行源生成支持

# 规则

- 添加针对MiniNamed特性的源生成能力
- 源生成的代码文件以.g.cs结尾
- 读取类的所有公开实例化属性，生成**Named子类**和**Defined子类**
- **Defined子类**按照类实际类定义生成
- 对象兼容Table特性
  - 检测到Table特性时，从table特性中读取Name属性作为**Named子类**的默认返回字符串
  - 未检测到Table特性时，以类名作为**Named子类**的默认返回字符串
- 属性兼容Column特性
  - 检测到Column特性时，从table特性中读取Name属性作为**Named子类**的默认返回字符串
  - 未检测到Column特性时，以类名作为**Named子类**的默认返回字符串
- 严格按照项目规范进行代码生成，评估可行性，当现有技术规范不满足需求时，停止代码生成并提示

# 目标

- 达到**生成代码示例**中的效果，格式完全一样

# 生成代码示例

```
namespace Hamster.Modules.Example.Simple.Entities;

public partial class Todo
{

    /// <summary>
    /// 命名
    /// </summary>
    /// <param name="alias"></param>
    public class Named(string alias = null)
    {
    
        /// <summary>
        /// 默认命名信息
        /// </summary>
        public static Named Instance { get; } = new();

        private readonly string _alias = alias;

        /// <summary>
        /// 通配符
        /// </summary>
        public string Any { get => string.IsNullOrWhiteSpace(_alias) ? "*" : $"{_alias}.*"; }

        /// <summary>
        /// Id
        /// </summary>
        public string Id { get => string.IsNullOrWhiteSpace(_alias) ? "id" : $"{_alias}.id"; }

        /// <summary>
        /// 标题
        /// </summary>
        public string Title { get => string.IsNullOrWhiteSpace(_alias) ? "title" : $"{_alias}.title"; }

        /// <summary>
        /// 字符串表示
        /// </summary>
        /// <returns></returns>
        public override string ToString()
        {
            return string.IsNullOrWhiteSpace(_alias) ? "todo" : _alias;
        }
    }

    /// <summary>
    /// 定义
    /// </summary>
    public class Defined
    {

        /// <summary>
        /// 默认定义信息
        /// </summary>
        public static Defined Instance { get; } = new();

        private readonly string _alias = alias;

        /// <summary>
        /// Id
        /// </summary>
        public string Id { get; } = nameof(Id);

        /// <summary>
        /// 标题
        /// </summary>
        public string Title { get; } = nameof(Title)

        /// <summary>
        /// 字符串表示
        /// </summary>
        /// <returns></returns>
        public override string ToString()
        {
            return "Todo";
        }
    }
}
```
