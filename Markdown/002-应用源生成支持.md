# 简介

针对MiniApp特性进行源生成支持

# 规则

- 创建Hamster.Generator子项目专用于源生成
- 添加针对MiniApp特性的源生成能力
- 源生成的效果代码参考TodoApp.i.cs实现
- 源生成的代码文件以.g.cs结尾
- 兼容Microsoft.AspNetCore.Mvc.Routing.HttpMethodAttribute特性设置来识别接口类型
- 读取的HttpMethodAttribute的HttpMethods属性来判断接口类型，而不是直接判断特性名称，方便支持任意自定义继承HttpMethodAttribute的特性，如项目中的MiniGetAttribute特性
- 支持同一个函数注册多种接口类型
- 只针对包含HttpMethod及继承特性的函数进行源生成
- 不要修改现有的App.cs应用代码

# 目标

- 只需要编写类似TodoApp.cs中的GetAllTodos函数定义，可以自动生成接口
