# 简介

针对MiniGroupAttribute特性进行源生成支持

# 规则

- 添加针对MiniGroup特性的源生成能力
- 源生成的代码文件以.g.cs结尾
- 读取程序集中所有的MiniAppAttribute特性定义的应用信息，并根据**应用匹配流程**进行匹配
- 严格按照项目规范进行代码生成，评估可行性，当现有技术规范不满足需求时，停止代码生成并提示

# 应用匹配流程

1. 从MiniGroupAttribute的Rule属性获取**匹配规则**
2. 将待匹配的类以**命名空间.类名**格式组合为**待匹配字符串**
2. 判断**待匹配字符串**与**匹配规则**进行比较
3. **匹配规则**中以'.'符号为标识符进行分段匹配，'*'星号为单一段的通配，'**'则代表多段通配
4. 匹配结果为true的类添加为有效的源生成项

# 目标

- 达到**生成代码示例**中的效果，格式完全一样

# 生成代码示例

```
using Hamster.Core;
using Hamster.Modules.Example.Simple.Controller;

namespace Hamster.Modules.Example.Simple;

public partial class SimpleGroup : IMiniGroup
{
    /// <summary>
    /// 映射
    /// </summary>
    /// <param name="routeBuilder"></param>
    public void Map(IEndpointRouteBuilder routeBuilder)
    {
        var group = routeBuilder.MapGroup("/simple");
        group.MapMiniApp<TodoApp>();
    }
}
```
